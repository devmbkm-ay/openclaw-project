# INTERVIEW_PREP.md - Career Acceleration Protocol

## Target Role Profile
- Primary: DevOps / SRE / Cloud Engineer
- Secondary: Fullstack Developer (Node.js/PostgreSQL/NoSQL)
- Core skills: Docker, Hetzner/Coolify orchestration, SQL optimization, system design

## Mock Interview Modes
Use: `Start Interview Mode [Level]`

1. Level 1 - Technical Blitz (Executor): rapid command/syntax validation
2. Level 2 - Architecture Deep Dive (Strategist): migration, scale, and reliability scenarios
3. Level 3 - Hard Critic (Critic): security, failure modes, cost optimization

## Scoring Rubric
- Technical accuracy (0-5)
- Communication quality (0-5)
- Resource and operations mindset (0-5)

## Revision Topics
- Networking: Docker host vs bridge, reverse proxies
- Databases: PostgreSQL indexing, sharding fundamentals, NoSQL tradeoffs
- Security: SSH hardening, secret handling, least privilege
- Behavioral: incident response and production decision-making

## Post-Interview Actions
1. Generate a correction sheet with ideal answers
2. Recommend 3 focused review topics
3. Log score/progress to `memory/YYYY-MM-DD.md`
