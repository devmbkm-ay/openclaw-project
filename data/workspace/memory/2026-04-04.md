# Durable Memories - 2026-04-04

## Project: BudgetApp
- **Architecture:** Monorepo (Turborepo) with Bun, Next.js (web), ElysiaJS (api), and Prisma/PostgreSQL.
- **Network Config:** Docker PostgreSQL is accessible from the agent via `172.16.0.1:5432` (gateway IP).
- **Authentication:** 
    - Custom JWT-like session stored in a cookie (`budgetapp_session`).
    - Password hashing uses `scryptSync` with a static salt `budgetapp-seed-salt` to maintain consistency between seed and runtime.
- **Frontend Ports:** Switched from `3000` to `3030` to avoid `EADDRINUSE` conflicts.
- **Design System:** High-fidelity "Glassmorphism" with Corail (`#FF453A`) and Blue/Green accents.
- **Fixes:**
    - Added `isClient` hydration guard to `AppNav` to prevent SSR/Client mismatch.
    - Standardized date format to ISO with timestamp for database compatibility.
    - Unified navigation bar styles for mobile-first feel.
